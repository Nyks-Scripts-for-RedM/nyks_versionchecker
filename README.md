# Nyks Scripts - Version Manifests

Centralized version repository for Nyks Scripts resources (RedM).

## Overview

This repository hosts version manifests used by our resources to notify server owners of new releases and changelogs.

## Available Manifests

- `nyks_birdpost.json` - Pigeon & Bird Post Delivery System

## Format

```json
[
  {
    "version": "1.0.4",
    "changelog": [
      "Bug fixes and performance improvements"
    ]
  }
]
```
